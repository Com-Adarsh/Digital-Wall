# Campus Wall

A custom Jekyll site for a student community wall. Students submit through a public form; an editor reviews each proposed post as a GitHub pull request; merging publishes it through GitHub Pages.

## Included

- Responsive home page, category filters, story cards, story pages, and submission page.
- Jekyll collection stored as Markdown files in `_stories/`.
- GitHub Actions build and deployment workflow.
- Editorial and Tally/Make launch guide in [SETUP.md](SETUP.md).

The submission page embeds the published Tally form. See `SETUP.md` to connect new responses to the review workflow.
